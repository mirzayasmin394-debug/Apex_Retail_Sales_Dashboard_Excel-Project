# Apex Retail Sales Dashboard | Microsoft Excel

## Project Overview

The **Apex Retail Sales Dashboard** is an interactive sales analytics project developed using Microsoft Excel. The dashboard provides a visual overview of business performance by presenting key sales metrics, regional performance, payment methods, product category profitability, and sales trends.

The goal of this project is to transform sales data into meaningful visual insights that help users understand business performance and make data-driven decisions.

## Key Performance Indicators (KPIs)

The dashboard highlights three important business metrics:

- **Total Sales:** 93,859
- **Total Profit:** 15,256
- **Total Quantity Sold:** 260

## Dashboard Features

### Interactive Filters (Slicers)
Users can filter dashboard information by:
- Region: East, North, South, West
- Payment Mode: Card, Cash, Online
- Category: Clothing, Electronics, Furniture, Home Decor, Others, Sports

### Data Visualizations

The dashboard includes five visualizations:

1. **Quantity by Payment Mode:** Compares the quantity of products purchased through different payment methods.
2. **Sales by Region:** Displays sales performance across four regions.
3. **Profit by Category:** Shows the percentage distribution of profit across product categories.
4. **Sales Trend:** Visualizes sales performance over time.
5. **Top 5 Salespersons:** Compares the sales performance of the top five sales representatives.
